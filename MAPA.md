# Mapa de los 100 agentes

5 empresas × 4 módulos. Cada agente tiene su ficha en `equipo/<empresa>/<módulo>/`.

| Módulo | Qué consigue |
| --- | --- |
| M1 Ventas | Se contesta todo, se revisan los leads, se agendan llamadas, se emiten presupuestos, se atiende soporte y se reporta |
| M2 Operaciones | Cada cliente nuevo se da de alta el mismo día y cada proyecto se actualiza y se envía antes de que nadie pregunte |
| M3 Backoffice | Las facturas salen a tiempo, los impagos se persiguen y las cuentas se concilian cada noche |
| M4 Inteligencia | Lee qué cerró, qué está atascado y qué costó dinero, y alimenta a los demás departamentos |
