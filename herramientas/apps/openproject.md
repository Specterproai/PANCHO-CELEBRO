# OpenProject — gestión de proyectos (alternativa a Jira / Asana)
- Repositorio: https://github.com/opf/openproject · Instalación Docker: https://www.openproject.org/docs/installation-and-operations/installation/docker/
- Dónde: VPS con Docker (mín. recomendado ~4 GB RAM para los tres servidores juntos; más holgado 8 GB).
- Usar la edición Community (gratis). No activar la prueba Enterprise.
- Registro: el administrador lo crea Pancho en el primer acceso.
- Agentes: API REST v3 con token personal de API (lo genera Pancho en Mi cuenta > Tokens de acceso).
