# Chatwoot — bandeja de atención al cliente (alternativa a Intercom / Zendesk)
- Repositorio: https://github.com/chatwoot/chatwoot · Docker: https://developers.chatwoot.com/self-hosted/deployment/docker
- Dónde: VPS con Docker (Postgres + Redis incluidos en el compose oficial).
- Canales: chat web, email, WhatsApp, Instagram, Telegram. Una bandeja por empresa.
- Agentes: API REST con token de acceso del agente; webhooks para respuestas automáticas.
