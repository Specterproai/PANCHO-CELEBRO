# Cal.diy — agenda y reservas (alternativa a Calendly)
- Repositorio: https://github.com/calcom/cal.diy · Imagen Docker: https://hub.docker.com/r/calcom/cal.diy
- Dónde: VPS con Docker + PostgreSQL.
- Aviso del proyecto: recomendado para uso personal/no productivo; para uso comercial a gran escala proponen Cal.com (de pago). Valorar antes de usarlo con clientes.
- Agentes: API v2 incluida.
