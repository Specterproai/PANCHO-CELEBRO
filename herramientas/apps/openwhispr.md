# OpenWhispr — dictado y transcripción (alternativa a Wispr Flow / Granola)
- Repositorio: https://github.com/OpenWhispr/openwhispr · Web: https://openwhispr.com
- Instalación: .dmg de macOS (Intel) desde https://github.com/OpenWhispr/openwhispr/releases/latest
- Modo gratuito: elegir modelos **locales** (Whisper / Parakeet). No activar OpenWhispr Cloud ni claves de API de pago.
- Permisos de macOS: micrófono y accesibilidad (para pegar el texto en otras apps).
- Agentes: tiene API pública y servidor MCP para leer notas y transcripciones.
