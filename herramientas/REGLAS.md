# Reglas para los agentes — Stack gratuito

Este repositorio define con qué herramientas trabajan los agentes de Pancho
(Cascade, Klasse, LexLegal, Specter AI, VANTIQ, marca personal).

## Regla principal
1. Para generar o gestionar cualquier contenido, usa **solo** las apps de `herramientas/apps/`.
2. **No** contrates, registres ni uses apps de pago (ElevenLabs, Loom, Notion de pago,
   Calendly, Intercom, Jira, Higgsfield, etc.) sin aprobación expresa de Pancho.
3. Si una tarea no se puede hacer con el stack gratuito, **para y pregunta** proponiendo
   la alternativa open source más cercana.
4. Nunca introduzcas contraseñas, claves de API ni datos de pago. Las credenciales las
   gestiona Pancho.

## Qué app usar para cada tarea
| Tarea | App | Dónde corre | Guía |
|---|---|---|---|
| Notas, wikis, briefs, calendarios editoriales, bases de datos de contenido | AppFlowy | iMac (escritorio) | `herramientas/apps/appflowy.md` |
| Dictado, transcripción de reuniones y vídeos, notas de voz | OpenWhispr | iMac (escritorio) | `herramientas/apps/openwhispr.md` |
| Grabación de pantalla, demos, tutoriales, vídeos para clientes | Cap | iMac (escritorio) | `herramientas/apps/cap.md` |
| Proyectos, tareas, sprints, roadmap por empresa | OpenProject | VPS (Docker) | `herramientas/apps/openproject.md` |
| Agenda, páginas de reserva de llamadas y reuniones | Cal.diy | VPS (Docker) | `herramientas/apps/cal-diy.md` |
| Atención al cliente: web chat, email, WhatsApp e Instagram en una bandeja | Chatwoot | VPS (Docker) | `herramientas/apps/chatwoot.md` |
| Generación de imágenes con IA | Open Generative AI (solo modo local) | Pendiente: requiere Apple Silicon/GPU | `herramientas/apps/open-generative-ai.md` |
| Voz con IA (clonación, locución, doblaje) | VoiceStudio | Pendiente: requiere Apple Silicon | `herramientas/apps/voicestudio.md` |
